MoneyMate V1
=============
Fresh offline personal finance tracker.

How to run:
1. Extract the ZIP.
2. Open index.html in a browser.
3. Add Income / Expense.
4. Data is stored locally on the device/browser.

V1 includes:
- Dashboard
- Income
- Expense
- Categories
- Date and notes
- Balance calculation
- Recent transaction history
- Delete transaction
- Offline local storage
- Mobile-friendly UI
